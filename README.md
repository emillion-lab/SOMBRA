# SOMBRA

Одитор на твърдения. Не потвърждава хипотези — разбива ги на проверими части, търси реални източници и записва резултата, за да може да бъде оспорен по-късно.

Фронтенд: https://emillion-lab.github.io/SOMBRA/

## Как работи

**Двупосочен пас.** Всяко твърдение се пуска два пъти през модела, паралелно и без двата паса да се виждат: единият търси доказателства *за*, другият *срещу*. Интервалите се обединяват, не се осредняват — когато двата паса не се съгласяват, несигурността се **разширява**. Несъгласие не може да произведе увереност.

**Източник без проверима референция се маркира като такъв.** Промптът изрично разрешава `"resolvable": false`. Това е позволеният изход вместо измисляне на сигнатура. Във фронтенда такива редове излизат зачеркнати.

**Независими срещу производни свидетелства.** Всеки източник носи `independent` и `derives_from`. Двайсет вторични текста, преразказващи един извор, не са двайсет доказателства.

**Карта на мълчанието.** За всяка липса се пита какво е трябвало да оцелее и се дава груб приор за оцеляемост на такъв документ. Липсата на доказателство и доказателството за липса се записват отделно.

**Собствена калибрация.** Твърдение може да се маркира като разрешено. `/api/calibration` смята Brier score и системния наклон върху разрешените. Без това инструментът е просто по-красив генератор на увереност.

## Калибрационен dataset

`calibration/calibration-set-2026-08.json` съдържа 30 твърдения от бита (химия, физика, електротехника, механика, биология, география, математика) с предварително известен верен отговор (`expected_verdict`) и очаквано ниво на несигурност (`expected_uncertainty`). Целта е стрес тест на собствената калибрация върху лесно проверими факти, извън историческата тематика, за която инструментът е построен.

```
SOMBRA_EP="https://sombra.mihov-emil.workers.dev" \
SOMBRA_TOKEN="som_..." \
npm run calibrate
```

Скриптът `scripts/run-calibration.mjs` пуска всяко твърдение през `/api/audit`, изчаква да приключи, маркира го през `/api/resolve` с истинския верен отговор и накрая отпечатва обобщение от `/api/calibration`. Отнема продължително време (30 последователни одита, всеки с реално търсене) — оставете го да завърши.

## Настройка

Базата D1 `sombra` е създадена и схемата е приложена.

Остават тайните:

```
wrangler secret put ANTHROPIC_API_KEY
wrangler secret put ADMIN_TOKEN
wrangler deploy
```

За автоматичен деплой през GitHub Actions — в Settings → Secrets: `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.

## Ограничение, което трябва да се знае

Инструмент, построен да търси заличаване, ще намира заличаване. Затова пасът „срещу" е равностоен, а не проформа. Ако регистърът след време показва, че почти всичко излиза потвърдено, проблемът е в инструмента, не в архива.
